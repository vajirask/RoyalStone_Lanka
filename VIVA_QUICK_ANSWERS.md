# VIVA QUICK ANSWERS: RoyalStone Lanka

## 💡 1. Why did you create this project? (The Reason)
"I created this project to modernize the Sri Lankan gemstone industry. The main problems are **lack of trust** and **fake stones**. By using **AI technology**, I created a way for anyone to identify gemstones for free. Combined with a **secure Marketplace**, it helps local sellers reach global buyers safely."

---

## 🛠️ 2. What challenges did you face? (The Problems)
*   **AI Accuracy**: Many gemstones (like Rubies and Spinels) look almost identical. I had to use **Transfer Learning** and high-quality datasets to teach the AI the small differences between stones.
*   **UI/UX for AI**: Making an AI tool feel 'professional' was hard. I solved this by adding the **Cyber Scan** animations and a detailed "Spectral Analysis" data stream.
*   **Security Integration**: Connecting the Frontend and Backend securely was a challenge. I implemented **JWT (JSON Web Tokens)** to manage user sessions across the platform.

---

## 💻 3. Basic Stack and Languages
*   **Languages**: JavaScript, TypeScript, HTML, CSS.
*   **Frontend**: React.js with Vite and Tailwind CSS.
*   **Backend**: Node.js and Express.js.
*   **Database**: MongoDB Atlas (NoSQL Cloud Database).
*   **AI Library**: TensorFlow.js.

---

## 🔮 4. Future Improvements (What's Next?)
*   **AR Try-On**: I want to add **Augmented Reality** so users can see how a gemstone ring looks on their hand using their camera.
*   **Blockchain**: I plan to integrate **Blockchain** to give every gem a digital "Certificate of Authenticity" that cannot be changed.
*   **Live Video Scan**: I want to move from photo uploads to **Real-time video identification**.

---

## 👨‍🏫 5. Expert Tip for Viva
If they ask **"Why use TensorFlow.js instead of Python?"**
> **Answer**: "Using TensorFlow.js allows the AI to run directly in the **browser**. This means the user's images are never sent to a server, which is much **faster** and provides **100% privacy** for the user."
